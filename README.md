# 吹牛 · 扑克牌

朋友之间的扑克心理战。电脑运行服务器，手机或电脑浏览器加入房间，最多 6 人。

## 启动

双击 `start.bat`，或执行：

```powershell
cd "d:\Documents\New project\card_bluff_web"
python server.py --host 0.0.0.0 --port 8080
```

本机访问 `http://localhost:8080`。

## 让朋友加入

1. 所有玩家安装并加入同一个 ZeroTier 网络（Windows / iOS / Android / macOS 都有客户端）。
2. 你启动服务器后，在终端里查看服务器打印的 IP。
3. 朋友在浏览器打开 `http://<你的ZeroTier-IP>:8080`，输入房间码和昵称加入。
4. 房主看到至少 2 人后点击「开始游戏」。

同一 WiFi 也可以直接用服务器打印的局域网 IP。如果 ZeroTier 在国内连接不稳，可优先使用蒲公英组网，或自建 ZeroTier Moon。

## 玩法要点

- 两副标准牌共 108 张（每副含 1 张大王、1 张小王，共 4 张王）。
- **大小王是万能牌**：可代替任意点数出牌，质疑时视为与所报点数匹配（4 张 2 + 小王可报「5 个 2」，被质疑判为真）；王本身不能被报点（报点仍为 2–A）。
- 持黑桃 3 的玩家先出；之后每轮无质疑结束时由本轮首家继续先出，有质疑时由没拿牌的赢家先出。
- 首家选择报点并必须先出牌（不能过牌）；后续玩家必须报同一报点。
- 每次可出 1-8 张，实际牌面可以任意混搭。
- 按座位顺序轮流：出牌 / 过牌 / 质疑。**过牌 = 本轮出局**，本轮内不再出牌或质疑，直到本轮结束；全员都过牌则本轮无质疑结束。
- **只能质疑上一个出牌的人出的最近一手**，不能质疑更早的牌。质疑成功（对方确实吹牛）→ 被质疑者拿回全桌牌，由质疑者下一轮先出；质疑失败（对方说真话）→ 质疑者拿回全桌牌，由出牌人继续先出。
- 打光手牌后仍需撑过本轮质疑；未被质疑或质疑为真即获胜。
- 回合计时 60 秒；超时若可质疑则自动质疑最近一手，若上一手是自己或未报点则自动出最小一张，手牌为空则自动过牌。

## AI 对手

- 等待房里**房主**可添加 AI 对手，并分别设置强度：简单 / 中等 / 困难；随时可移除或改强度。
- 真人 + AI 合计 **≥2 人即可开局**（房主加 1 个 AI 也能单机练习），总人数仍上限 6。
- AI 只看自己的手牌和公开信息（桌面、各家手牌数、质疑翻开的牌）决策，不偷看；轮到它会“思考”3–5 秒再行动，困难 AI 更敢质疑、还会记住谁爱吹牛。
- AI 是游客身份：不计入账号战绩与排行榜。

## 音频文件

- `bgm.mp3`：等待房和牌桌背景音乐。
- `sounds/play.mp3`：出牌音效。
- `sounds/win.mp3`：胜利音乐。
- `sounds/lose.mp3`：失败音乐。

音频文件缺失或加载失败时会自动静默降级，不影响游戏。快捷短语会作为普通聊天消息发送。

## 账号与战绩

- 首页可注册/登录账号，或选择游客模式；游客可游玩和查看排行榜，但不计入个人战绩。
- 账号、对局历史和排行榜保存在 `data/bluff.db`，服务器重启后仍然保留。
- 登录账号后可从首页查看「我的战绩」和「排行榜」；游戏结束后会显示本局战报。
- 战绩指标：总局数、胜场、胜率、吹牛成功率、质疑准确率。
- 排行榜按胜场降序、胜率降序排序，游客不会出现在榜单中。


服务器只使用 Python 标准库，无需安装依赖；房间状态保存在内存中，服务器重启后房间会清空。
